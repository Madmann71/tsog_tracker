Двухуровневая защита (ПИН-код + Токен облака):

          
1. Читатели (без ПИН-кода и без токена): вводят только ID базы (Gist ID) и обновляют остатки кнопкой «Загрузить (Pull)». Даже зная ID базы, перезаписать облако без токена технически невозможно.

          
2. Мастера (вход по ПИН-коду): разблокируют интерфейс своим ПИН-кодом и выгружают изменения в облако (`Push`), причем список мастеров и их ПИН-кодов синхронизируется вместе с базой.
